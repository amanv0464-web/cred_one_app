# CRED Product Improvement Case Study

## Overview
This project analyzes a product growth opportunity for CRED using a structured product management framework.

## Problem Statement
How can CRED increase user engagement and payment frequency among existing users?

## Objectives
- Improve user retention
- Increase monthly active users
- Encourage more credit card bill payments

## Framework Used
- Product Thinking
- User Persona
- Pain Point Analysis
- Prioritization
- Solution Design
- Success Metrics

## Proposed Solution
Two features built on one principle: don't add new behaviors, sync with existing ones.
CRED One Card — A physical card that works everywhere the user already spends: metro, restaurants, fuel, groceries. Automatic reward optimization across all linked cards on the backend. One card in the wallet, zero change in user behavior.
CRED Lite — A simplified mode inside CRED with two options on entry: Pay or Bill. Strips the cluttered experience down to its core for users who open the app with one clear purpose.

## Success Metrics
Monthly Financially Engaged Users — users who complete at least one non-bill action inside CRED per month.
